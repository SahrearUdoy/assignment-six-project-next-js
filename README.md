# FitLog - Workout Library

FitLog is a workout library website.Users can browse different workouts, view workout details,add exercises to today's plan,save workouts for later,and track completed exercises.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- React Toastify
- JavaScript

## Features

- Responsive workout library
- Workout details page
- Add workouts to Today's Plan
- Save workouts for later
- Maximum 5 workouts in Today's Plan
- Workout sorting by duration,calories,and rating
- Mark workouts as Done
- Remove workouts from Today's Plan
- Toast notifications
- Dynamic Plan and Saved counters
- Responsive Navbar and layout
- Loading animation while workout data is loading

## Main Pages

- Home
- Workouts
- Workout Details
- My Plan

## API

Workout data is loaded from the FitLog API.
